숏폼 생성

서버에는 저장하지 않으며, 편의를 위해 이 기기(휴대폰·PC)에만 기억할 수 있습니다.

Gemini API 키 발급 방법
  1. Google AI Studio (aistudio.google.com/apikey)에 접속합니다.
  2. Google 계정으로 로그인합니다.
  3. 「API 키 만들기」 또는 「Create API key」를 클릭합니다.
  4. 생성된 키(AIza...)를 복사해 위 입력란에 붙여넣습니다.

API 사용 요금은 Google 계정(본인)에 청구됩니다.
