귀하께서 보내주신 API·데이터 이용 중단 요청을 확인하였습니다.

요청하신 사항에 따라 아래와 같이 조치를 완료하였습니다.

## 1. API 및 자동 수집 중단

- search-etf.com API(`get_etf_stock_info.php` 등) 호출 및 자동 수집·동기화를 중단하였습니다.
- 서버 설정 `SEARCH_ETF_CALLS_ALLOWED=0`으로 API 호출을 차단하였습니다.
- 관련 스크립트는 정책상 API 접속 시 실행되지 않도록 변경하였습니다.
- ETF 데이터 동기화 예약 작업(cron)을 서버에서 제거하였습니다.

## 2. 공개 콘텐츠 비공개

- ETF 월배당 시트, ETF 허브 등 관련 공개 페이지·표·차트 노출을 비공개(접속 불가) 처리하였습니다.
- 해당 URL은 사이트맵·검색 노출에서 제외하였습니다.

## 3. 문구 정리

- 사이트 내 search-etf.com 명칭·내부 파라미터·분류 기준을 직접 인용·표기한 문구를 삭제·수정하였습니다.

## 4. 향후 조치

- search-etf.com API 및 데이터에 대한 호출·자동 수집·동기화·재게시를 하지 않겠습니다.
- 사이트는 블로그·질문·답변 중심으로 운영합니다.

## 추가 요청

삭제·수정이 더 필요한 URL·페이지·문구가 있으시면 알려주시면 즉시 반영하겠습니다.
