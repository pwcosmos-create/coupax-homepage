# 🎨 Designer Guide V1.0 - Top 3 Ad Mockup Final Specification (Mockup A, B, C)

## 🎯 개요
본 문서는 '보배시즌'의 핵심 메시지 3가지(신뢰성, 수익 증명, 통제권)를 바탕으로 제작되는 광고 소재의 최종 비주얼 레이아웃을 정의합니다. 모든 디자인은 확정된 Design System 컴포넌트와 컬러 팔레트를 따르며, 개발 및 마케팅팀이 즉시 가이드라인으로 사용할 수 있도록 합니다.

## 🎨 공통 디자인 시스템 (재확인)
*   **Primary Color:** Midnight Blue (`#0A1931`) - 권위, 배경
*   **Secondary Color:** Deep Copper (`#B8860B`) - CTA, KPI 강조, 최종 결론
*   **Accent Color:** Clear Sky Blue (`#ADD8E6`) - 데이터 흐름, 연결성 (Flow)
*   **Typography:** Pretendard (Bold/Regular 혼합 사용)

## 🖼️ Mockup A: 신뢰 증명 (DPSR Focus)
*   **[목표]**: 시스템적 안정성을 통해 잠재 고객의 불안감을 해소하고 기술적 우위를 각인.
*   **[배경]**: Midnight Blue (`#0A1931`) 단색 배경을 사용하여 무게감과 깊은 신뢰를 부여합니다.
*   **[레이아웃 구성]**:
    1.  **(Headline)**: [시스템 안정성 기반 서비스] $DPSR$ 99.9% 확보 (Midnight Blue 배경, Pretendard Bold, 48pt)
    2.  **(Core Component)**: **Trust Proof Module**를 전면 배치합니다. 실제 데이터 흐름을 시각화하는 `Clear Sky Blue` 연결선(Flow Line)과 실시간 KPI 그래프를 메인 비주얼로 사용합니다. (애니메이션 가이드라인 필수 명시).
    3.  **(Call to Action)**: "시스템적 안정성, 지금 경험하세요." 텍스트와 함께 **CTA Button Component** (`#B8860B`)를 하단에 배치하여 행동을 유도합니다.

## 📈 Mockup B: 수익 증명 (ROI Focus)
*   **[목표]**: 실시간 데이터 기반의 재무적 이득을 직관적으로 제시하여 즉각적인 구매 전환 유발.
*   **[배경]**: 미묘한 그라데이션 배경 (Midnight Blue $\to$ Clear Sky Blue).
*   **[레이아웃 구성]**:
    1.  **(Headline)**: [광고 소재 성공률의 비밀] 데이터 기반 ROI 극대화 입증. (Pretendard Bold, 36pt)
    2.  **(Core Component)**: **Mockup B-Graph**를 배치합니다. 그래프의 Y축과 X축 주요 마커 포인트에는 Deep Copper (`#B8860B`)를 사용하여 수치적 강조 효과를 극대화하고, 상승 추세선은 Clear Sky Blue를 사용합니다.
    3.  **(Trust Element)**: 그래프 근처에 간결하게 압축된 `Trust Proof Module`을 삽입하여 "이 데이터는 시스템적으로 검증됨"이라는 신뢰 요소를 추가합니다.
    4.  **(Call to Action)**: 화면 우측 하단, 시선 집중 영역에 **CTA Button Component** (`#B8860B`)를 크고 대비되게 배치합니다.

## 👑 Mockup C: 통제권 확보 (클라이맥스)
*   **[목표]**: 브랜드의 최종적 가치(통제력, 시스템 권한)를 제시하며 높은 권위로 마무리하는 클라이맥스 소재.
*   **[배경]**: Midnight Blue (`#0A1931`) 단색 배경을 유지하여 최고 수준의 신뢰와 무게감을 부여합니다.
*   **[레이아웃 구성]**:
    1.  **(Headline)**: \[보배시즌\] 미래 자산 설계, 궁극의 통제권 확보. (세리프 계열 폰트 느낌 가미, Pretendard Bold)
    2.  **(Core Component)**: **Layered System 다이어그램**을 중앙에 배치합니다. 가장 핵심적인 '통합 제어 코어' 노드는 Deep Copper (`#B8860B`)로 하이라이트하고 주변 연결선은 Clear Sky Blue를 사용합니다.
    3.  **(Messaging)**: "데이터가 곧 통제권입니다."와 같은 강력한 문구를 배치하여 메시지를 각인시킵니다.
    4.  **(Call to Action)**: 화면 최하단, 여백을 충분히 확보하고 간결하게 **CTA Button Component**를 배치합니다.
